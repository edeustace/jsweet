# Generated GWT TS

most of the ts files are generated so are ignored.
We just need the package.json/tsconfig.json and user-ts/index.ts


This repo contains a TS generated by java2typescript.

The goal is to prove that we can compile java -> ts, the compile ts -> js.


It's all a bit manual atm - but I'm sure we can smooth things out.


## Install

```shell
pnpm install
```

## Build

```shell
cd sample-ts
pnpm vite dev
# go to localhost:5173
```

Here you'll see errors w/ the TS and you can start picking your way through them.
